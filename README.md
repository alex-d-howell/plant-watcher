# Plant Watcher

Hi! This project is intended to be an organized place for raspberry pi plant watcher setup.

At a high level the first iteration of this project will be: 
 - the raspi to be able to turn on at certain points in the day
 - take an image of my plants that is then uploaded to an S3 bucket
 - image is processed by an ai model to determine if the plant needs watering
 - Sends a notification if the plant should be watered/looks dry/looks frail

Phase 2 will be developing a dashboard to manage different components. raspi management, ai decision making management, and plant watcher history tracking.
